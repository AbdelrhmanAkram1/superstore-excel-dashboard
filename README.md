# Superstore Dashboard (Excel)

An interactive Excel dashboard built on the Sample Superstore dataset, designed to let a business owner explore sales, profit, and regional performance without touching a single formula.

## What's inside
- **PivotTables** connected to the raw Superstore data (Orders, Products, Customers)
- **Slicers** for Region, Category, and Order Date — filter everything on the dashboard with one click
- A single-page layout combining KPI cards, a monthly sales trend, and a category/region breakdown

## Dataset
Sample Superstore — a public retail dataset covering orders, products, customers, sales, and profit across US regions.

## Tools
Excel (PivotTables, PivotCharts, Slicers, conditional formatting)

## What I learned
- How far native Excel tools can go before a project actually needs a BI tool like Power BI
- How to structure raw transactional data so a PivotTable can actually make sense of it
- Designing a dashboard that answers a business question at a glance, not just displaying numbers

## How to view it
Download the `.xlsx` file and open it in Excel (2016 or later) — slicers and PivotTables are fully interactive.
